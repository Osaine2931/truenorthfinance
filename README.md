# Prime Invest Dashboard

Build a premium investment platform inspired by AssetProton and the modern dashboard layout shown in the attached reference image. The platform must support both desktop and mobile with a responsive, app-like experience. Use React + Vite + TypeScript, Tailwind CSS, shadcn/ui, Supabase, Cloudflare Pages, and GitHub as the only source of truth.

The UI should look modern, clean, premium, and trustworthy with a white, blue, and subtle gold color palette. Use rounded cards, smooth animations, premium typography, glassmorphism where appropriate, and professional charts. Do not create a trading platform. This is a long-term investment platform.
